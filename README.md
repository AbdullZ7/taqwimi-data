# بيانات مناسبات «تقويمي»

المناسبات التي يعرضها تطبيق تقويمي: الإسلامية، الأيام الوطنية، مواعيد المدفوعات السعودية،
التقويم الدراسي، والعطل الأمريكية. التطبيق يحمّل أحدث نسخة مرة في الأسبوع من:

https://abdullz7.github.io/taqwimi-data/occasions.json

## الملفات التي تعدّلها
- `sets/<id>.json`: ملف صغير لكل مجموعة (مثل `sets/school.json` للتقويم الدراسي، `sets/gov-salary.json` للرواتب).
- `index.json`: رقم الإصدار `version`، تاريخ التحديث `updated`، البلدان، وترتيب المجموعات في الإعدادات.

`occasions.json` **لا يُعدَّل باليد**: يبنيه GitHub تلقائيًا من الملفات أعلاه مع كل دفع، ويفحصه، ثم ينشره.

## خطوات التحديث (من موقع GitHub مباشرة)
1. افتح الملف المطلوب في `sets/` واضغط ✏️، عدّل التاريخ أو أضف سطرًا، ثم Commit.
2. افتح `index.json`: ارفع `version` بواحد وغيّر `updated`. بدون رفع الإصدار لن تأخذه الأجهزة.
3. انتظر دقيقة: علامة ✓ خضراء على الـ commit تعني أن الملف سليم ونُشر. علامة ✗ تعني خطأ في الكتابة (افتح Actions لرؤية السطر).
4. يصل التحديث للأجهزة خلال أسبوع، أو فورًا من الإعدادات ← عن التطبيق ← «تحديث».

مع كل إصدار جديد للتطبيق يُنسخ `occasions.json` إلى `app/public/data/` في مستودع التطبيق.

## شكل المجموعة
```json
{
  "id": "school", "country": "sa", "name": "التقويم الدراسي ١٤٤٨", "icon": "cap", "color": "#2c5f8d",
  "hint": "يظهر تحت اسم المجموعة في الإعدادات",
  "note": "ملاحظة لك، لا يقرؤها التطبيق",
  "dated": [["2026-08-23", null, "بداية العام الدراسي"], ["2026-11-20", "2026-11-28", "إجازة الخريف"]]
}
```
أنواع التواريخ، ويمكن الجمع بينها في المجموعة الواحدة:

| المفتاح | المعنى |
|---|---|
| `hijri: [[شهر, يوم, الاسم]]` | كل سنة هجرية |
| `yearly: [[شهر, يوم, الاسم]]` | كل سنة ميلادية |
| `nth: [[شهر, يوم الأسبوع, الترتيب, الاسم]]` | مثل «الاثنين الثاني من أكتوبر»؛ يوم الأسبوع 0 = الأحد، الترتيب -1 = الأخير |
| `monthly: { "day", "fri", "sat", "fixed" }` | مدفوعات شهرية: اليوم، والإزاحة بالأيام إن صادف جمعة أو سبتًا، و`fixed` استثناءات معلنة مثل `{ "2026-05": 24 }` |
| `dated: [[من, إلى أو null, الاسم]]` | تواريخ محددة أو مدى |

- `country`: `sa` أو `us` (من `index.json`)؛ المجموعة تتبع مفتاح بلدها في الإعدادات. بدونه تكون عامة (مثل الإسلامية).
- `fixed: true` على المجموعة: بلا مفتاح خاص بها؛ تعمل متى عمل بلدها (العطل الأمريكية).
- الأيقونات من أيقونات التطبيق: `money`, `cap`, `arabesque`, `flag-sa`, `flag-us`, وبقية أيقونات المواعيد.
- فاصلة زائدة أو ناقصة تكسر الملف؛ الفحص الآلي يخبرك بالسطر.

# بيانات مناسبات «تقويمي»

المناسبات التي يعرضها تطبيق تقويمي: الإسلامية، الأيام الوطنية، مواعيد المدفوعات السعودية،
التقويم الدراسي، والعطل الأمريكية. التطبيق يحمّل أحدث نسخة مرة في الأسبوع من:

https://abdullz7.github.io/taqwimi-data/occasions.json

## الجداول التي تعدّلها (CSV)
كل جدول لنوع واحد، صف لكل مناسبة، وعناوين الأعمدة بالعربية:

| الملف | ماذا فيه | الأعمدة |
|---|---|---|
| `dated.csv` | تواريخ محددة أو مدى (التقويم الدراسي، Easter) | المجموعة، من، إلى (فارغ ليوم واحد)، الاسم |
| `yearly.csv` | ما يتكرر كل سنة | المجموعة، التقويم (هجري / ميلادي)، الشهر، اليوم، الاسم |
| `monthly.csv` | المدفوعات الشهرية | المجموعة، اليوم، الجمعة، السبت (كم يومًا يتحرك إن صادف جمعة أو سبتًا؛ -1 = قبلها بيوم، 1 = بعدها بيوم) |
| `fixed.csv` | استثناءات معلنة لدفعة بعينها | المجموعة، الشهر (YYYY-MM)، اليوم |
| `nth.csv` | «الاثنين الثاني من أكتوبر» ونحوه | المجموعة، الشهر، يوم الأسبوع (0 = الأحد … 6 = السبت)، الترتيب (-1 = الأخير)، الاسم |
| `sets.csv` | المجموعات نفسها كما تظهر في الإعدادات، بترتيبها | المعرّف، الاسم، البلد، الأيقونة، اللون، الوصف، بلا مفتاح |
| `countries.csv` | البلدان | المعرّف، الاسم، العلم |
| `meta.csv` | رقم الإصدار وتاريخ التحديث | المفتاح، القيمة |

`occasions.json` **لا يُعدَّل باليد**: يبنيه GitHub تلقائيًا من الجداول مع كل دفع، ويفحصه، ثم ينشره.

## خطوات التحديث
1. عدّل الجدول المناسب: من موقع GitHub (✏️ ثم Commit)، أو نزّله وافتحه في جداول Google / Numbers / Excel ثم ارفعه.
2. في `meta.csv` ارفع `version` بواحد وغيّر `updated`. بدون رفع الإصدار لن تأخذه الأجهزة.
3. انتظر دقيقة: ✓ خضراء على الـ commit تعني أن الجداول سليمة ونُشرت؛ ✗ تعني خطأ، وActions يذكر لك الملف والسطر والسبب بالعربية.
4. يصل التحديث للأجهزة خلال أسبوع، أو فورًا من الإعدادات ← عن التطبيق ← «تحديث».

مع كل إصدار جديد للتطبيق يُنسخ `occasions.json` إلى `app/public/data/` في مستودع التطبيق.

## تنبيهات
- التواريخ بصيغة `YYYY-MM-DD` دائمًا. Excel يحوّلها عند الحفظ إلى صيغة محلية مثل `8/23/2026`؛ لذلك احفظ من Excel بصيغة «CSV UTF-8» واضبط عمود التاريخ كنص، أو استعمل جداول Google أو محرر GitHub. الفحص الآلي يرفض أي صيغة أخرى ويخبرك بالسطر.
- الأرقام الهجرية والميلادية في الجداول بالأرقام العادية (1–12)، والأسماء كما تحب أن تظهر.
- فاصلة داخل اسم؟ ضع الاسم بين علامتي تنصيص `"..."`.
- `البلد` في `sets.csv`: `sa` أو `us`؛ فارغ = مجموعة عامة (مثل الإسلامية). `بلا مفتاح` = `نعم` تعني أن المجموعة تعمل متى عمل بلدها بلا مفتاح خاص.
- الأيقونات من أيقونات التطبيق: `money`, `cap`, `arabesque`, `flag-sa`, `flag-us`، وبقية أيقونات المواعيد.
- محليًا: `node build.mjs` ثم `node validate.mjs` يعطيان النتيجة نفسها التي يعطيها GitHub.

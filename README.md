# بيانات مناسبات «تقويمي»

`occasions.json` هو ملف المناسبات الذي يقرأه تطبيق تقويمي: المناسبات الإسلامية، الأيام الوطنية،
مواعيد المدفوعات السعودية، التقويم الدراسي، والعطل الأمريكية. التطبيق يحمّل أحدث نسخة منه مرة
في الأسبوع من:

https://abdullz7.github.io/taqwimi-data/occasions.json

## لتحديث المناسبات
1. عدّل `occasions.json`.
2. ارفع `version` بواحد وحدّث `updated` (YYYY-MM-DD). التطبيق لا يأخذ الملف إلا إذا كان إصداره أعلى مما لديه.
3. `node validate.mjs` للتأكد من سلامة الملف (يعمل تلقائيًا مع كل دفع).
4. ادفع إلى `main`؛ خلال دقيقة يُنشر، وخلال أسبوع يصل كل الأجهزة (فورًا عند الضغط على «تحديث» في الإعدادات ← عن التطبيق).

## شكل الملف
كل مجموعة (`sets[]`) لها `id` و`name` و`icon` و`color`، واختياريًا `country` (من `countries`) و`hint`، ونوع واحد أو أكثر:

| المفتاح | المعنى |
|---|---|
| `hijri: [[شهر, يوم, الاسم]]` | كل سنة هجرية |
| `yearly: [[شهر, يوم, الاسم]]` | كل سنة ميلادية |
| `nth: [[شهر, يوم الأسبوع, الترتيب, الاسم]]` | مثل «الاثنين الثاني من أكتوبر»؛ يوم الأسبوع 0 = الأحد، الترتيب -1 = الأخير |
| `monthly: { day, fri, sat, fixed }` | مدفوعات شهرية: اليوم، والإزاحة إن صادف جمعة أو سبتًا، و`fixed` استثناءات معلنة `{ "YYYY-MM": يوم }` |
| `dated: [[من, إلى أو null, الاسم]]` | تواريخ محددة أو مدى |

الأيقونات يجب أن تكون من أيقونات التطبيق (مثل `money`, `cap`, `arabesque`, `flag-sa`, `flag-us`).
